# My Tango Note

> *A quiet corner for words worth keeping.*
> *英語の輪郭が、1単語ずつ見えてくるノート。*

便利になるほど、英語を覚えられない。AIで瞬時に訳せる時代に、気になった単語を、調べて終わり、にしない。ちゃんと自分のノートに残していくための、ちいさな単語ノート。

A personal English vocabulary notebook for the AI era — a quiet space to keep the words you actually want to remember.

🌐 [mytangonote.com](https://mytangonote.com)

---

## なぜ作ったか — Why this exists

AIで仕事のスピードは爆発的に上がった。英文メールはすぐに訳してくれるし、返信案も英語で作ってくれる。英語を使ったコミュニケーションは、確かに進んでいる。

けれど、自分に「残った英語」がないことに、気がついた。

**My Tango Note** は、気になった単語やフレーズをAIと一緒に深く調べ、自分だけの単語ノートとして蓄積するための小さな道具です。

- 「単語帳」というより、**英語の私的なノート**
- 「暗記」じゃなく、**気になった言葉を腹落ちさせる**
- 「100単語覚える」じゃなく、**今週の3単語をちゃんと残す**

---

## 何ができるか — What it does

英語の単語・フレーズ・熟語を入力すると、**英語と日本語の両方で** 並んだリッチなエントリーが生成されます:

- **意味**（多義的なニュアンス含めて）
- **例文**（あなたが選ぶモードに合わせた文脈で）
- **Notes**（コロケーション、類義語、語源、使い分け、発音）

エントリーはノート形式で蓄積され、検索・フィルタ・エクスポートできます。

### モード切替

同じ単語でも、文脈が違えば例文も変わるべき。My Tango Note は4つのモードを切り替えられます:

- 💼 **Business** — ミーティング、メール、プレゼン
- 📚 **Literature / Academic** — 本、論文、エッセイ
- ☕ **Casual** — 日常会話、友人との会話
- 📰 **News / Current Affairs** — ジャーナリズム、時事

### その他の機能

- 🔊 **音声読み上げ** — 単語と例文を発音してくれる(Web Speech API、無料)
- 🔍 **全文検索** — 意味・例文・Notes すべて横断
- 🏷️ **タイプ別フィルタ** — 名詞 / 動詞 / イディオム etc.
- 📤 **エクスポート** — CSV / JSON(Google Sheets にも取り込める)
- 🔒 **完全プライベート** — データは自分のブラウザ内のみ(サーバー送信なし)

## 始め方 — Getting started

### 1. `index.html` をダウンロード

[Code → Download ZIP](https://github.com/mytangonote/notebook/archive/refs/heads/main.zip) でも、個別ファイル `index.html` を右クリック → 名前を付けて保存、でもOK。

ダウンロードしたファイルには2つの HTML が入っています:

- **`index.html`**: あなたの単語ノート(最初は空っぽ)
- **`examples.html`**: 14個の見本エントリーが入った参考用のノート(「どんな感じになるのか」を見るためのファイル)

普段使うのは `index.html` です。`examples.html` は参考にするだけで、削除しても OK です。

### 2. お使いのAI(Claude / ChatGPT / Gemini など)に、スタータープロンプトを送る

「これからこういう使い方をするよ」という最初の宣言です。1回だけ実行すれば、その後の会話でAIが常にこの形式で応答してくれます。

```
これからあなたと一緒に、英語の単語・フレーズ・イディオムを記録する
バイリンガル単語ノートを作っていきます。

# 私の使い方

私が英語の単語・フレーズ・熟語を伝えたら、それを以下の JavaScript
オブジェクト形式で返してください。私はその結果を自分のノート
(HTML ファイルの entries 配列) にコピペで追加します。

# 出力フォーマット

{
  phrase: '入力された英語',
  type: '品詞・分類',
    // 'noun', 'verb', 'idiom', 'phrase', 'phrasal verb', 'adjective' など
  meaningEN: '英語での意味 (必要に応じて番号付きで複数)',
  meaningJP: '英語の意味に対応する自然な日本語',
  exampleEN: '実際に使われそうな自然な例文',
  exampleJP: '例文の自然な日本語訳',
  notes: 'ニュアンス・コロケーション・類義語・発音・語源・注意点など。
          プレーンテキスト、Markdown 不要',
  dateAdded: 'YYYY-MM-DD 形式の今日の日付'
}

# モード(任意)

私が「ビジネスモードで」「文学モードで」「カジュアルモードで」
「ニュースモードで」と指定したら、そのモードに合わせて例文や
注釈の質感を整えてください。

- ビジネスモード: 仕事の文脈。notes の冒頭に【Business mode】を付ける
- 文学・学術モード: 本、論文、エッセイ。深いニュアンスにも触れる
- カジュアルモード: 日常会話、SNS、雑談
- ニュースモード: 報道。notes の冒頭に【News mode】を付ける

モードの指定がなければ、その単語に最も自然な文脈で返してください。

# 注意点

- 日本語訳は、辞書的な直訳ではなく自然な日本語に
- notes には、その単語を「腹落ちさせる」ための情報を入れる
  (コロケーション、類義語、発音、語源、よくある誤用、関連表現など)
- 英語と日本語の例文は、内容が対応するように
- 出力は JavaScript オブジェクトリテラル形式のみ。
  コードブロックの中に入れて返してください

# 最初のやりとり

私が次のメッセージで英単語を送ります。
準備ができたら「準備できました」とだけ返してください。
```

### 3. 単語を投げて、エントリーをノートに追加

気になった英単語・フレーズをAIに送ると、JavaScript オブジェクト形式でエントリーが返ってきます。

それを、ダウンロードした `index.html` を開いて、`entries` 配列の中(直前のエントリーの後)にコピペで追加します。

### 4. ブラウザで `index.html` を開く

保存したファイルをダブルクリックするだけ。サーバーは不要、すべてローカルで完結します。

## どのAIで使えますか? — Which AI works?

My Tango Note は、**Claude / ChatGPT / Gemini** など、現代の主要なAIチャットで動きます。スタータープロンプトは同じものをそのまま使えます。

### 推奨

| AI | おすすめ度 | 備考 |
|---|---|---|
| **Claude** (Sonnet 4 / Opus 4) | ⭐⭐⭐ | 開発時に検証、日本語のニュアンスが自然 |
| **ChatGPT** (GPT-4o / o1) | ⭐⭐ | 構造化出力が安定 |
| **Gemini** (2.5 Pro) | ⭐⭐ | 同上 |

### 出力の質感について

AIによって出力の質感(日本語の自然さ、例文の温度感、Notes の情報密度)に小さな違いが出ます。気に入った返答が得られなかった時は、「もう少し自然な日本語で」「ビジネスっぽい例文で」「もっと詳しく」など追加で指示してください。

## ご利用にあたって — A few things to know

このノートは個人プロジェクトとして作っています。気軽に使ってもらえると嬉しいですが、いくつか頭に留めておいていただけたら:

- **AI の出力は完璧ではありません**。仕事や試験など重要な場面で使う英語は、ネイティブスピーカーや専門家にも確認することをおすすめします
- **データはあなたのブラウザ内 (HTML ファイル内) に保存されます**。安心な一方で、ファイルを失うと中身も失われます。大切なエントリーは Export 機能 (CSV / JSON) で定期的にバックアップしてください
- **個人プロジェクトのため、保証やサポートは提供していません**。バグ報告や改善のアイデアは GitHub Issues で大歓迎です
